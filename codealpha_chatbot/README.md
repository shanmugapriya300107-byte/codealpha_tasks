# 🤖 Smart Rule-Based Chatbot

A simple desktop chatbot built with Python and Tkinter that responds to predefined commands using rule-based logic. This project demonstrates basic chatbot development, GUI design, and event-driven programming in Python.

## Features

* 👋 Greeting responses (hello, hi, hey)
* 🧑 Remembers the user's name during the session
* 🕒 Displays current time
* 📅 Displays current date
* 😂 Random programming jokes
* 🧮 Basic calculator functionality
* ❓ Built-in help menu
* 🧹 Clear chat option
* 🚪 Exit command support
* 🖥️ User-friendly Tkinter GUI

## Technologies Used

* Python 3
* Tkinter
* Random Module
* Datetime Module

## Supported Commands

| Command           | Description                |
| ----------------- | -------------------------- |
| hello / hi / hey  | Greeting message           |
| my name is <name> | Store user name            |
| what is my name   | Recall stored name         |
| time              | Show current time          |
| date              | Show current date          |
| joke              | Tell a random joke         |
| calculate 5+10    | Perform calculation        |
| help              | Display available commands |
| bye               | Exit conversation          |

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/smart-rule-based-chatbot.git
```

2. Navigate to the project folder:

```bash
cd smart-rule-based-chatbot
```

3. Run the application:

```bash
python chatbot.py
```
